# Security

## Reporting

If you identify a security issue, please report it privately to the repository owner rather than opening a public issue containing sensitive details.

## Repository Policy

This repository must not contain:

- credentials or API keys;
- participant or retailer data;
- private research records;
- deployment secrets;
- backup passphrases;
- environment-specific confidential configuration.

All example data must be synthetic.

## Safe Contributions

Before committing:

1. review staged files for secrets and identifiers;
2. verify that datasets are synthetic;
3. avoid copying files from private research repositories unless they have been independently rewritten and reviewed;
4. keep environment files such as `.env` out of version control.
